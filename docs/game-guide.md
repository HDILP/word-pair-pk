# 词对 PK · 游戏说明书

> 英语单词配对双人 PK 游戏。人教版高中英语 7 册 + 课外词汇，共 5254 词。
> 更新日期：2026-08-08

---

## 一、游戏简介

在 16 张卡片（8 张英文 + 8 张中文释义）中找出配对：点击一张英文卡和它对应的中文卡，配对成功即消除。

核心体验：
- **双人对战**：同屏分边，手速 + 记忆力对决
- **打击感**：每次点击都有 Phigros 风格打击特效（三色连击渐变）
- **学习闭环**：所有模式的错词自动进入复习系统，配错的词会"记得你"

---

## 二、快速开始

1. 打开 https://word-pair-pk.hdilp.top（手机/电脑均可）
2. 首页选择模式 → 选择词表（教材 → 单元，可多选）→ 开始
3. 3-2-1 倒计时结束后，点击卡片配对：先点一张，再点它的对应卡
4. 配对正确：卡片金色光晕消除 + 英文朗读 + 连击 +1
5. 配对错误：卡片红闪 + 抖动，连击清零

**操作**：鼠标点击 / 手机触摸，双人可同时操作（多点触控）。

## 三、游戏模式详解

### 1. 双人 PK（竞速）👥

- 同屏分左右两半，P1 与 P2 各自拥有一副独立的 8 对牌（互不干扰）
- 各自计时，**先配完 8 对的一方获胜**
- 双方可同时操作（多点触控支持）
- 胜利者进入排行榜（按用时排名）
- 双方的错词都会进入复习系统

### 2. 单人挑战 🎯

- 一人配完 8 对，记录用时，冲击个人最佳（PB）
- **5 颗心**：每配错一次 -1 颗，0 颗提前结束（考验稳定性，不只是手速）
- 结束后错词自动进入复习系统

### 3. 抢答 PK ⚡

- **公共牌池**：16 张牌（8 对）由双方共同操作，同一副牌
- 规则：
  - 点一张卡 = 选中（标记为你的）
  - 你选中的卡，**对方可以抢**——对方先点到它的配对卡，这对归对方
  - 错误点击不扣分、不惩罚，但也不能顶掉对方的选中
  - 谁完成配对，这对归谁
- 8 对全部消除后：**得分多者胜；平分比用时**
- 考验：手速、记忆力、还有对对手的预判

### 4. 听力挑战 🎧

- 每轮 TTS 朗读一个英文单词，从 4 张中文卡中选出正确释义
- 答对 +1 分并进入下一轮；答错 -1 颗心（共 5 颗）
- 共 8 轮，可随时点"重听"再听一遍
- 点错的词自动进入复习系统
- 0 颗心提前结束

### 5. 例句配对 💬

- 卡面不再是单词，而是**英文例句**——句子里的目标词加粗高亮
- 玩法：读例句理解语境 → 配对对应的中文释义（8 对）
- 配对成功：高亮绿光 + **TTS 朗读整句例句**（不只是单词，练语境听力）
- 配对失败：红闪 + 连击清零，错词自动进入复习系统
- 提示：不认识的词也能靠句子语境猜出来——这正是练阅读理解的思路
- 全部 **5254 词**均带例句，任意教材都能玩

### 6. 单词复习 📖

三种复习模式（利特纳记忆盒子算法，间隔 0/1/2/4/8/16 天）：

| 模式 | 内容 |
|------|------|
| 自由练习 | 从已选词表中随机抽 8 词，无计时无压力 |
| 今日复习 | 今天到期的词（按记忆曲线） |
| 错题特训 | 盒子 1 的顽固错词（最容易忘的） |

- 配对正确 → 盒子升级；配对错误 → 回到盒子 1
- 所有游戏模式的错词都会自动汇入复习系统

### 7. 每日挑战 ⚡

- 每天一个固定主题局（同一天所有设备同一批词，由日期决定）
- 完成记录最快时间，连续打卡天数会累计
- 同样会触发随机事件

## 四、通用机制

### 连击 Combo 🔥

- 连续配对成功 +1，屏幕显示连击数（渐变金色大字）
- 配对失败清零，并短暂显示"断连"
- **打击特效颜色随连击变化**：连击 0-2 黄色 → 3-5 蓝色 → 6+ 红色
- 双人各自独立计数

### 随机事件 🎲

每局开局随机触发 1 个公平事件（对双方效果相同）：

| 事件 | 效果 |
|------|------|
| 🌫️ 迷雾开局 | 倒计时结束后卡片半透明 2.5 秒，凭记忆抢开局，随后渐显 |
| 🔀 中途洗牌 | 开局 5 秒后未匹配的卡片重新洗牌（已配对的保持不动） |

### 打击特效 ✦

- Phigros 风格打击反馈：扩散方框 ×2 + 收缩/扩张圆 + 双 90° 圆弧 + 方形粒子
- 颜色：左键黄色 / 右键蓝色 / 中键红色（触摸为黄色，复习模式恒黄）
- 音效：drag / tap / flick 三种打击音
- **可在首页关闭**（"打击特效"开关，状态会记住）

### 英文发音 🔊

- 配对成功自动朗读英文（Web Speech API）
- 图鉴、复习等界面点击发音按钮可重复听

## 五、学习系统

### 复习盒子（利特纳记忆曲线）

- 存储于本地（localStorage），不需要账号
- 盒子 1~5，间隔 0/1/2/4/8/16 天
- 错得越多，越频繁出现；全对则越拉越长

### 弱点雷达 📡

双人 PK 结束后弹窗显示：
- 胜负与用时
- 双方错词 Top 3（按错误次数）
- 提示已自动加入今日复习

### 单词图鉴 📖

- 配对成功的单词自动收集进图鉴（所有模式都算）
- 支持搜索、按教材分组、点击发音
- 未收集的单词显示为灰色占位（不剧透释义）
- 收集进度条：已收集 / 5254

---

## 六、排行榜与个人最佳

- 双人 PK 胜者进入排行榜（localStorage 保存，可导出/导入 JSON）
- 单人挑战记录个人最佳时间（PB）
- 排行榜按用时升序

## 七、安装与更新

### 安装到桌面（PWA）📱

在线版支持"安装到桌面"：
- 手机 Chrome/Edge：菜单 → "安装应用" / "添加到主屏幕"
- 电脑 Chrome/Edge：地址栏右侧安装图标
- 安装后离线也能玩（自动缓存）

### 本地离线版 💾

- 点击页脚"↓"可下载完整单文件（index.html，约 1.3MB，含全部词库与音效）
- 下载后双击即可离线运行（无需网络）
- 本地版会自动检测线上新版本（页脚显示"新版本可用"提示）

### 版本信息

- 页脚显示构建版本号，点击可查看构建时间与版本来源
- 粉色圆点 = 已连接远程检测；灰色 = 未连接
