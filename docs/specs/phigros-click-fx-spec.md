# Phigros 风格点击特效 — 实现规格

> 来源：用户需求（2026-08-05），原样记录，参数为最终约束
> 状态：待实现
> 相关：太虚五转 D1 手感层（docs/reports/word-pair-pk-freshness-taixu-summary-20260805.md）

## 需求

实现一个 "Phigros" 风格的鼠标点击特效：在点击位置同时触发一组几何打击反馈元素。

## 全局参数

- 缓动：所有缩放/位移动画统一使用 **EaseOutCubic**
- 生命周期：所有元素动画完成后，整体在 **300ms** 内淡出
- 颜色：**仅限三色**——黄 #FFD84D / 蓝 #4D9DFF / 红 #FF5A5A（由按键/模式决定，见"变色规则"；**无白色默认**，全局默认色=黄色）
- 整体不透明度默认 **0.8**

## 元素规格（点击时同时触发全部 6 项）

### 1. 主正方形边框

- 未旋转的正方形边框，从 **50% 扩大到 100%**（以最终尺寸为基准）
- 线宽全程不变
- 不透明度 **100%**
- 四条边必须首尾严密接合、**闭合无缺口**

### 2. 旋转 45° 正方形边框

- 旋转 45° 的**等大**正方形边框，与主边框同步扩大
- 每帧面积始终保持为主正方形边框的 **144%**（即边长为其 120%）
- 线宽从**很粗**（粗细等于内部填充正方形的边长）逐渐变细（内轮廓往外推），最终与主正方形边框线宽一致
- 不透明度始终 **50%**
- 边角同样严密接合

### 3. 收缩实心圆

- 实心圆，从与主正方形初始大小相同的尺寸**缩小为一个很小的圆点**
- 不透明度始终 **100%**

### 4. 扩张半透明圆

- 另一个实心圆，从**很小圆点**扩大为"小圆点最终半径的 **200%**"
- 不透明度始终 **50%**

### 5. 双 90° 圆弧

- 两条 **90°** 圆弧线
- 半径为主正方形尺寸的 **75%**
- 线宽为主正方形边框的 **200%**
- 不透明度 **100%**
- 两条弧分别从**右上方**和**左下方**起始、**顺时针旋转 30°** 后停止
- 起始与结束角度整体再**逆时针偏移 30°**（即结束方向为原东北/西南方向逆时针转 30°）

### 6. 方形散射粒子

- 若干**不同大小、不同不透明度**的纯正方形粒子，从中心向外迅速飞出
- 正方形自身**不旋转**（不是两个长方形叠成的十字型）
- 位移使用 EaseOutCubic
- 到位后慢慢淡出

## 变色规则

- 事件源：`pointerdown`（监听 window，不 preventDefault/stopPropagation）
- 左键（button===0）→ 黄色；右键（button===2）→ 蓝色；其他键 → 红色
- 触摸 / 笔（pointerType==='touch'|'pen'）→ 黄色（无视 button）
- Off 模式（复习三模式，currentView==='reviewGame'）→ 恒黄色，无视一切按键
- 优先级：Off 模式 > 按键
- 所有 6 元素 + 粒子统一使用当前特效色（无白色）

- 源文件位于仓库外，不复制进仓库

## 生命周期

1. 点击 → 6 项元素同时生成、同时开始动画
2. 元素动画完成 → 整体 300ms 统一淡出 → 移除

- Off 模式下恒为黄色

## 实现约束（建议）

- 特效层不拦截事件：点击/触摸仍需穿透到卡片（pointer-events: none）
- 支持多实例并发（快速连点、双人同时操作）
- 低端设备/弱动画偏好（prefers-reduced-motion）下可整体禁用或降级
- PRO 音频文件需随包内置（离线/PWA 场景不可依赖网络）
