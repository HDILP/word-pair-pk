# 词对 PK 玩法升级 — 想法池（osborn 太虚一转·散怀）

## P1 自由发散（44 个）

### 玩法机制（1-12）

1. [P1] **连击 Combo 系统**：连续配对成功触发连击，连击数加成得分/加速，断连清零并扣分。竞速感 + 反馈感双增强
2. [P1] **能量大招**：配对正确积攒能量条，满了可手动释放大招——时间冻结 3 秒 / 对方牌面模糊 5 秒 / 本局双倍分
3. [P1] **限时风暴模式**：总倒计时内无限配对，错对只影响剩余时间，追求单位时间吞吐量
4. [P1] **对抗道具**：P1 配对成功后获得道具并丢向 P2——遮罩一张卡 / 抖动对方牌面 / 交换双方各一张卡的位置
5. [P1] **动态难度**：按双方当前胜率自动调卡片密度（8 对→10 对）或单词难度，菜鸡互啄也有悬念
6. [P1] **组词模式**：配对成功后追加一题——从 3 个选项中选正确搭配/例句补全，答对才算完整得分
7. [P1] **三消变体**：把配对做成三消网格，三张相邻同单词即消除，消除链触发连锁特效
8. [P1] **单词赛车**：双方各一辆小车，配对成功推进，先冲过 10 格终点者胜——把竞速可视化
9. [P1] **抢答模式**：中央公共卡片池，双方抢同一张（先点到者得），考验手速+记忆
10. [P1] **单词枯竭战**：总牌数固定，配对的词不再补位，最后只剩最难的一组，看谁先卡死
11. [P1] **不对称家庭模式**：家长 vs 孩子——家长时间减半或卡片更大更少，难度天然不对称仍可公平对决
12. [P1] **轮次制三局两胜**：单局短平快，中场休息动画+比分板，戏剧张力拉满

### 视觉特效（13-19）
